GMX、Synthetix、Curve → 被认为是 DeFi 中比较“现金流导向”的代币。
dYdX、Sushi、LooksRare → 通过手续费奖励来激励代币持有者。
包装方式：通常叫 质押奖励 / 手续费返还，而不是 分红，避免触及证券法律。

4.三种扩容机制的优缺点
+----------------+-------------------------+----------------------------+-----------------------------+
|   扩容方案     |         优点             |           缺点              |       适用场景               |
+----------------+-------------------------+----------------------------+-----------------------------+
| Layer 1 扩容   | - 提升基础性能（TPS）    | - 去中心化和安全性可能下降  | 适合短期快速缓解性能瓶颈      |
| （链上扩容）   | - 用户体验简单，直接用   | - 扩容受物理瓶颈限制        | 公链性能升级，如以太坊合并前  |
|                |                         | - 节点硬件门槛提升          |                             |
+----------------+-------------------------+----------------------------+-----------------------------+
| Layer 2 Rollup | - 不牺牲安全性，依托主链 | - 用户体验稍复杂            | DeFi、NFT、大规模交易        |
| （Optimistic   | - 成本低，吞吐量大       | - 资金退出有延迟（乐观类）  | 高频小额交易，DApp 生态       |
| / ZK）         | - 灵活支持多种应用       | - 技术复杂度高              |                             |
+----------------+-------------------------+----------------------------+-----------------------------+
| 分片 Sharding  | - 多链并行处理，扩展强   | - 跨分片通信复杂            | 长期基础设施扩展方案          |
|                | - 节点门槛可降低         | - 实现难度高，安全挑战大    | 适合大规模用户和应用场景      |
|                | - 理论上可线性扩展       | - 数据一致性处理复杂        |                             |
+----------------+-------------------------+----------------------------+-----------------------------+
分片（Sharding）可以理解为把一条区块链“拆分成多条并行的链片段”，每个片（Shard）负责处理自己的一部分交易或数据，这样多片同时运行，就能大幅提升整体吞吐量。

我给你举个类比：

传统单链（未分片）：
就像一个高速收费站只有一个窗口，所有车辆都要排队缴费 → 处理速度受限。

分片（Sharding）：
把收费站拆成 10 个窗口，不同车辆可以走不同窗口 → 并行处理，效率提升。
