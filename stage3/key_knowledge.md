1.各层layer功能简介
+---------+--------------------+-----------------------------------+
|  Layer  | 功能定位            | 代表 Token / 项目                 |
+---------+--------------------+-----------------------------------+
| Layer 3 | 应用层（DApp）      | UNI（Uniswap）、AAVE、DYDX、AXS   |
|         | 去中心化应用、游戏  | （DeFi、GameFi 等应用 Token）     |
+---------+--------------------+-----------------------------------+
| Layer 2 | 扩容层              | OP（Optimism）、ARB（Arbitrum）   |
|         | Rollup、状态通道等  | MATIC（Polygon）、IMX（ImmutableX）|
+---------+--------------------+-----------------------------------+
| Layer 1 | 基础区块链          | ETH（Ethereum）、BTC（Bitcoin）   |
|         | 主链安全与共识      | SOL（Solana）、APT（Aptos）、SUI  |
+---------+--------------------+-----------------------------------+
| Layer 0 | 网络/互操作层       | DOT（Polkadot）、ATOM（Cosmos）   |
|         | 跨链通信、底层框架  | CELR（Celer）、L0 协议类项目      |
+---------+--------------------+-----------------------------------+

2.各layer代币功用
+---------+--------------------+-------------------------------+
|  Layer  | 代表 Token / 项目  | 代币主要作用                   |
+---------+--------------------+-------------------------------+
| Layer 0 | DOT（Polkadot）    | Staking（保障中继链安全）、治理 |
|         | ATOM（Cosmos）     | 链间通信费用、治理投票         |
+---------+--------------------+-------------------------------+
| Layer 1 | ETH（Ethereum）    | Gas 费、Staking（PoS）、治理   |
|         | BTC（Bitcoin）     | 记账单位、支付、抵押品         |
|         | SOL（Solana）      | Gas 费、Staking、治理投票      |
+---------+--------------------+-------------------------------+
| Layer 2 | OP（Optimism）     | 治理（链上治理提案、投票权）   |
|         | ARB（Arbitrum）    | 治理（DAO 投票权）             |
|         | MATIC（Polygon）   | Gas 费、Staking、治理          |
+---------+--------------------+-------------------------------+
| Layer 3 | UNI（Uniswap）     | 治理（协议升级、费率调整）     |
|         | AAVE（Aave）       | 抵押、治理、风险安全机制       |
|         | DYDX（dYdX）       | 手续费折扣、治理投票           |
+---------+--------------------+-------------------------------+
注意，layer3上的还没有做到利润分配的项目代币，但是有其他绕开的准利润分配方式

3.DApp 代币分红/利润分享清单
+----------+----------------------+------------------------------------------+
| 项目     | 代币                | 分红/利润分配机制                         |
+----------+----------------------+------------------------------------------+
| GMX      | GMX / GLP           | 质押 GMX 获得 30% 平台手续费（ETH/AVAX）   |
|          |                      | 持有 GLP 获得 70% 平台手续费              |
+----------+----------------------+------------------------------------------+
| Synthetix| SNX                  | 质押 SNX 可获得合成资产交易费（sUSD 分红）|
+----------+----------------------+------------------------------------------+
| Curve    | CRV + veCRV          | 锁仓 CRV 成为 veCRV，获得交易手续费分成   |
+----------+----------------------+------------------------------------------+
| dYdX v3  | DYDX                 | 质押 DYDX 参与安全池，可分配部分交易费    |
+----------+----------------------+------------------------------------------+
| SushiSwap| SUSHI + xSUSHI       | 质押 SUSHI → xSUSHI，可获得交易手续费分红 |
+----------+----------------------+------------------------------------------+
| LooksRare| LOOKS                | 持币质押可分配市场交易手续费（ETH 分红）  |
+----------+----------------------+------------------------------------------+
| Pancake  | CAKE                 | 质押 CAKE 参与收益池，有手续费奖励        |
+----------+----------------------+------------------------------------------+
GMX、Synthetix、Curve → 被认为是 DeFi 中比较“现金流导向”的代币。
dYdX、Sushi、LooksRare → 通过手续费奖励来激励代币持有者。
包装方式：通常叫 质押奖励 / 手续费返还，而不是 分红，避免触及证券法律。
